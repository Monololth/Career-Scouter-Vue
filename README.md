# Career-Scouter FrontEnd

This is the Career Scouter Front End Repository.
Note that there is no BackEnd for Career Scouter as of now, and all data is managed by Front End, which is a barebones implementation considering if the data gets too large, it increases load times for users. This needs to be taken into account in the future.

Suggestion is to develop backend to handle the data and FrontEnd then fetches the data from backend.

## Recommended Setup

Use [Docker](https://www.docker.com) to make container of Career Scouter and host it with your setup.

## Customize configuration

See [Documentation](https://wimma-lab-2023.pages.labranet.jamk.fi/pengwin-media/core-career-scouter/).

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
